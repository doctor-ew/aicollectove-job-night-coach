# Jobs Night Resume Alignment Coach

A portable prompt kit for AI Collective / AtlantaTech Vibe Night Jobs Night.

**Start with [coach/START-HERE.md](coach/START-HERE.md).** Paste that entire file into a new AI conversation, then supply your resume and a job description. No installation or API key is required by the kit. The host supplies the model and any file-reading or browsing capabilities.

The coach compares the whole resume against every JD component, asks one focused question at a time, suggests evidence-backed wording, and assembles only accepted edits. Every delivered resume includes a separate evidence companion.

First release: copyable text/Markdown outputs. It is not a hosted application, ATS predictor, Word exporter, or recruiting service. ChatGPT, Claude, Perplexity and other hosts can be tried with pasted text; named-product compatibility is not implied without a recorded test. Review the final resume yourself before using it.
